##  Sobre el Proyecto

Esta es la página de presentación (Landing Page) oficial de **CeTe**, una plataforma SaaS B2B desarrollada por el equipo Nexxus. Su propósito principal es comunicar la propuesta de valor comercial, detallar los planes de suscripción y servir como puerta de enlace directa hacia la aplicación web principal.

##  Características Principales

* **Diseño Corporativo (B2B):** Interfaz limpia y profesional estructurada bajo la identidad visual de Nexxus (Tonos *Primary Blue* `#0A2540` y *Accent Orange* `#FF6A00`).
* **Responsive Design:** Adaptabilidad total para dispositivos móviles, tablets y pantallas de escritorio sin depender de frameworks externos.
* **Navegación Fluida (Smooth Scroll):** Enrutamiento interno suave para una exploración ágil de beneficios y soluciones.
* **Integración Directa con la SPA:** Los *Call-to-Actions* (Iniciar Sesión, Prueba Gratis) están dinámicamente enrutados hacia el Frontend transaccional.
* **Pricing Escalonado:** Visualización clara de los planes de suscripción (Emprendedor, MYPE Pro, Expansión) orientados a diferentes segmentos del mercado.

##  Stack Tecnológico

* **Estructura:** HTML5 Semántico.
* **Estilos:** CSS3 (Vanilla puro) utilizando variables globales (`:root`) para consistencia de marca.
* **Tipografía:** Google Fonts (Roboto para lectura, Montserrat para encabezados).
* **Alojamiento:** GitHub Pages.

##  Ecosistema del Proyecto

La Landing Page actúa como la capa de marketing dentro de una arquitectura mayor. El ecosistema completo de CeTe se compone de:

1. **[Landing Page (Presentación)](https://nexxus-ops.github.io/FrontEnd-CeTe/)**: Interfaz actual.
2. **Frontend (App Transaccional)**: SPA desarrollada bajo principios de Domain-Driven Design (DDD) con Vue.js y PrimeVue.
3. **Fake API (Mock Backend)**: Base de datos simulada con `json-server`, desplegada en la nube a través de Render para soportar la persistencia de datos durante demostraciones.
