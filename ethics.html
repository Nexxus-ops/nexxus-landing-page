Project ethics

Accurate evidence

The team records implemented capabilities, limitations and verification results. Future features are distinguished from demonstrated functionality.

Collaboration

Each participant must contribute real work and be able to explain it. Authorship and participation records should match the evidence.

Responsible demonstration

Use authorized data, preserve original sources, protect credentials and report defects transparently. Review accessibility and user feedback throughout the project.

Ética del proyecto

Evidencias precisas

El equipo registra capacidades implementadas, limitaciones y resultados de verificación. Las funciones futuras se distinguen de la funcionalidad demostrada.

Colaboración

Cada integrante debe aportar trabajo real y poder explicarlo. La autoría y los registros de participación deben coincidir con las evidencias.

Demostración responsable

Usa datos autorizados, conserva las fuentes originales, protege credenciales y comunica los defectos de forma transparente. Revisa accesibilidad y observaciones de usuarios durante el proyecto.
