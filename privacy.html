Privacy information

Data used

Registration stores company name, RUC, business address, account email and a password hash. Operational records include products, movements, purchases, sales and dispatch details.

Purpose and access

The application uses these data to authenticate users, separate company records and demonstrate business workflows. Administrators assign employee roles. Passwords are not included in API responses.

Local preferences

The site stores the chosen language in browser local storage. The application stores its session in session storage and clears it on sign-out. No advertising tracking is configured in this project.

Requests

Use fictional information for demonstrations. Direct data access or deletion requests to the project team through the repository. A production retention policy requires a separate operational decision before commercial use.

Información de privacidad

Datos utilizados

El registro almacena nombre de empresa, RUC, dirección, correo de la cuenta y un hash de contraseña. Los registros operativos incluyen productos, movimientos, compras, ventas y despachos.

Propósito y acceso

La aplicación utiliza estos datos para autenticar usuarios, separar registros empresariales y demostrar los flujos del negocio. El administrador asigna roles. Las respuestas del API no incluyen contraseñas.

Preferencias locales

El sitio conserva el idioma elegido en el almacenamiento local del navegador. La aplicación conserva la sesión en el almacenamiento de sesión y la elimina al salir. Este proyecto no configura seguimiento publicitario.

Solicitudes

Usa información ficticia para las demostraciones. Dirige solicitudes de acceso o eliminación al equipo del proyecto mediante el repositorio. Una política productiva de conservación requiere una decisión operativa antes del uso comercial.
